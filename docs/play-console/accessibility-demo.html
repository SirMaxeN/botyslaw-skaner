What the recording shows

  1. Main screen with automatic and manual reading.
  2. Full in-app disclosure; user declines, then returns and accepts.
  3. Android accessibility permission and enabled service.
  4. Separate Android screen-capture consent.
  5. User-confirmed reading areas and navigation controls.
  6. User-started saved navigation and inventory scrolling, with visible STOP and Finish list controls.
  7. Editable results for review before synchronization.

This is a game resource-reading utility, not an accessibility tool. The optional service executes a fixed user-configured route. It does not purchase, summon, merge or forge items. Screen recognition runs locally through separately authorized MediaProjection capture. Accessibility window contents are not retrieved. Discord synchronization is optional and separate from the accessibility gestures.

The video shows the controls, not a separate STOP demonstration. Estimated readings remain labeled for user review. No claim of perfect counting is made.
